Plataforma de Inspección Preoperacional de Seguridad Vial

Cliente: ESS
Fecha: 31 de agosto de 2026
Alcance de este documento: Recomendación de hosting, base de datos y almacenamiento para poner la plataforma en producción

1. Entendimiento de la necesidad

ESS cuenta con una aplicación ya construida y probada que digitaliza la inspección preoperacional de vehículos, con el siguiente flujo operativo:

  • El trabajador realiza la inspección diaria del vehículo desde la aplicación.
  • El supervisor revisa y aprueba o rechaza, con firma digital posterior a la decisión.
  • El sistema genera el formato oficial FO-SVS-23 en PDF, listo para archivo o auditoría.
  • La dirección cuenta con un tablero ejecutivo de seguimiento, y el área administrativa gestiona usuarios y vehículos.

La escala inicial de operación es de 8 trabajadores, realizando una inspección diaria cada uno — aproximadamente 240 inspecciones al mes. Es una carga operativa baja: la prioridad no es la capacidad de procesamiento, sino la confiabilidad de los registros (al tratarse de un documento regulatorio) y un costo mensual predecible.

2. Arquitectura recomendada

La aplicación ya está construida de forma independiente de un proveedor específico: la base de datos usa el estándar PostgreSQL, y el almacenamiento de archivos usa el protocolo estándar S3, compatible con múltiples proveedores. Esto permite elegir la opción más simple de administrar sin modificar una sola línea de código.

Los tres componentes — aplicación, base de datos y almacenamiento de archivos — quedan bajo una sola cuenta y una sola factura en Railway, incluyendo certificado SSL automático y copias de seguridad por snapshot.

3. Por qué Railway frente a otras alternativas evaluadas

OpciónEvaluación
VPS autoadministrado (ej. Hostinger VPS) Costo base más bajo, pero el cliente pasa a ser responsable de instalar y mantener PostgreSQL, aplicar parches de seguridad y gestionar backups manualmente. Riesgo alto para un sistema que produce un documento regulatorio.
Multi-proveedor (hosting + base de datos + almacenamiento por separado) Más flexible para escalas grandes, pero implica varias facturas y paneles de administración distintos — complejidad innecesaria para 8 usuarios.
Railway RECOMENDADO Plataforma administrada: base de datos y almacenamiento incluidos en la misma cuenta, SSL automático, backups incluidos. Costo previsible y acorde al volumen actual de operación.

5. Sobre la garantía del costo de $20/mes

¿Cómo funciona el cobro? El plan Pro de Railway funciona como un piso: los USD $20 mensuales incluyen USD $20 de crédito de consumo real (cómputo de la aplicación + base de datos + almacenamiento). Si el consumo se mantiene dentro de ese crédito, el cliente paga exactamente $20/mes — nada adicional.

Con el volumen actual (8 trabajadores, ~240 inspecciones al mes), la aplicación está inactiva la mayor parte del tiempo, la base de datos es pequeña y el volumen de fotos/PDF generado es bajo. Con ese perfil de uso, es razonable esperar que el consumo real quede muy por debajo del crédito incluido, y que la factura se mantenga en $20/mes.

Salvedad honesta: este es un modelo de pago por uso, no una tarifa plana garantizada contractualmente por Railway. La estimación anterior está basada en el volumen de operación descrito por el cliente; se recomienda revisar la primera factura real tras el lanzamiento para confirmarla con datos de producción.
